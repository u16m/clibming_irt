# 項目反応理論によるクライマーの能力とグレードの数値化

## はじめに
クライミングにおいて、グレードを測る客観的な指標がない。
そのため各ジムやセッターの主観によるグレード設定が行われており、
自分がどれだけのグレードを登れるのかが把握しづらい。
本研究では、テストの回答分析に用いられる項目反応理論(IRT)をクライミングに適用し、
登攀結果からグレードを数値化することを提案する。
一般的なスポーツとは異なり、クライミングは対人対戦の成績ではなく、
特定の課題の登攀結果を競うものであり、項目反応理論の応用先として自然であると考えた。
具体的には、2019年ワールドカップの結果をもとに、
クライマーの能力、課題の識別力、課題の難易度をパラメータとした3パラメータモデルのIRTを構築し、
それぞれの数値を推定した。
本手法を適用することにより、グレードの客観的なスコアだけではなく、
クライマーの能力とキーポイントとなった課題を統計的に推定することが可能になる。

## 考察
パラメータ設定によって結果が若干変化する。
### thetaについて
年間優勝を争ったアダム・オンドラと楢崎智亜が1,2のスコアとなっており概要は正しい
でも事前分布が正規分布と対数正規分布なのにこれでいいのかな。
### betaについて
完登者が少ない課題のbetaが減少している。
中でも、アダム・オンドラと楢崎智亜が完登できなかった課題についてはより差がつく結果となっている。
これは登ったクライマーの能力を反映したグレードの推定が行われていることを示している。

### alphaについて
全員が完登した課題はスコアが大きくなっている。
ちょっとよくわからん。どう説明したらいいんや。

## 結論
IRTをクライミングに適用すると、クライマーの能力、グレード、識別力が数値化できることを示した。
本研究ではワールドカップの結果をデータとしているが、
多数のクライマーの実際のジムでの登攀結果を得ることができれば、
クライミングにおけるグレードの標準化ができるのではないかと考えている
本研究では、登攀結果を2値で示しているが、アテンプト数やゾーンを考慮した確率モデルに拡張することも考えられる。
