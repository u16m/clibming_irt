# 項目反応理論によるクライマーの能力とグレードの数値化

## はじめに
クライミングにおいて、グレードを測る客観的な指標がない。
そのため各ジムやセッターの主観によるグレード設定が行われており、
自分がどれだけのグレードを登れるのかが把握しづらい。
本研究では、テストの回答分析に用いられる項目反応理論(IRT)をクライミングに適用し、
登攀結果からグレードを数値化することを提案する。
一般的なスポーツとは異なり、クライミングは対人対戦の成績ではなく、
特定の課題の登攀結果を競うものであり、項目反応理論の応用先として自然であると考えた。
具体的には、2019年ワールドカップの結果をもとに、
クライマーの能力、課題の識別力、課題の難易度をパラメータとした3パラメータモデルのIRTを構築し、
それぞれの数値を推定した。
本手法を適用することにより、グレードの客観的なスコアだけではなく、
クライマーの能力とキーポイントとなった課題を統計的に推定することが可能になる。

## 提案手法
### 項目反応理論
項目反応理論(Item Response Theory; Item Latent Theory, IRT) とは、
評価項目群への応答に基づいて、被験者の特性（認識能力、物理的能力、技術、知識、態度、人格特徴等）や、
評価項目の難易度・識別力を測定するための試験理論である。
[wikipedia](https://ja.wikipedia.org/wiki/%E9%A0%85%E7%9B%AE%E5%BF%9C%E7%AD%94%E7%90%86%E8%AB%96)

これをクライミングにおける能力推定に利用する。

よくある設定では、下記の3変数を用いて、被験者がある項目に正答する確率をモデル化する。
- 人パラメータ: $${\theta}$$
  - 各受験者の特性の大きさを表す実数値
- 識別パラメータ: $${\alpha}$$
  - 項目が被験者の能力を識別する力を表す実数値
- 難易度パラメータ: $${\beta}$$
  - 項目の難しさを表す実数値

これらとシグモイド関数を用いて、下のようなモデル化を行う。

$$P(r|{\alpha},{\beta},{\theta}) = 1 / 1+exp(-{\alpha}({\theta}-{\beta}))$$

このモデルをクライミングに応用することで、クライマーの能力や課題の難易度を統計的に推定することができる。

### クライミングへの適用

#### 問題設定

項目反応理論をクライミングに応用するにあたり、下記のような問題設定を行う。

クライマーの集合を$I$, 課題の集合を$J$とおく。

それぞれのクライマーは能力$${\theta_{i}}$$をもち、 各課題は識別力${\alpha_{j}}$, 難易度${\beta_{j}}$をもつとする。

クライマー${i}{\in}{I}$が課題${j}{\in}{J}$を登り、リザルト${r_{ij}}{\in}{\{0,1\}}$を得るとしたとき、

その結果から、${\theta}$, ${\alpha}$, ${\beta}$を推定することが目標である。

#### 定式化

クライマー${i}$が課題${j}$を完登する(${r_{ij}=1}$)確率を以下で定める。

$P({\theta_{i}, {\alpha_{j}, {\beta_{j}}}})=1 / 1+exp(-{\alpha}({\theta}-{\beta}))$

(完登できない(${r_{ij}=0}$)場合は$1 - P({\theta_{i}, {\alpha_{j}, {\beta_{j}}}})$となることに注意。)

ここで、${\alpha}$, ${\beta}$, ${\theta}$の事前分布をそれぞれ下記とする。

${\alpha} {\sim} {lognormal({\mu_{\alpha}, {\sigma_{\alpha}}})}$

${\beta} {\sim} {normal({\mu_{\beta}, {\sigma_{\beta}}})}$

${\theta} {\sim} {normal({\mu_{\theta}, {\sigma_{\theta}}})}$

するとあるリザルト集合${R}$についての尤度${L}$は下記のようにかける。

${L} = {\prod_{i{\in}I}}{\prod_{j{\in}J}} P({r_{ij}} | {\theta_{i}, {\alpha_{j}, {\beta_{j}}}}) {P({\theta_{i}})P({\alpha_{j}})P({\beta_{j}})}$

これを最大化するような ${\alpha}$, ${\beta}$, ${\theta}$を推定する。

### パラメータ推定

パラメータを推定する際、${\alpha}$, ${\beta}$, ${\theta}$を同時に推定すると、よい値が得られないらしい。

そのため、${\alpha}$, ${\beta}$,と${\theta}$はステップを分けて推定する。

今回は、尤度を${\theta}$について周辺化して${\alpha},{\beta}$を推定し、その後MAP推定を利用して${\theta}$を求める。

#### 周辺尤度最大化

${L}$について${\theta}$を周辺化し、下記のように変形する。

${L(r|{\alpha}, {\beta})} = {\prod_{i{\in}I}}{\prod_{j{\in}J}} {\int}P({r_{ij}} | {\theta_{i}, {\alpha_{j}, {\beta_{j}}}}){P({\theta})d{\theta}}{P({\alpha_{j}})P({\beta_{j}})}$

このとき、積分部分の計算が難しいので、ガウス・エルミート求積法を用いて近似計算を行った。

最適化は勾配降下法を用いて数値最適化を行う。

#### MAP推定によるtの推定
推定した${\alpha, \beta}$で${\theta}$を推定する。

${L(r|{\alpha}, {\beta})} = {\prod_{i{\in}I}}{\prod_{j{\in}J}} P({r_{ij}},{\theta_{i}}; {\alpha_{j},}{\beta_{j}},){P({\theta_{i}})}$

最適化は勾配降下法を用いて数値最適化を行う。

## 実験設定

### 使用データ
IFSCの2019年ボルダリングワールドカップ男子のデータを使用。

([ここ](https://www.ifsc-climbing.org/)から頑張って作成する)

今回はアテンプト数、ゾーンに関係なく、完登で1, 未完登で0とした。

### ハイパーパラメータの設定

${\mu_{\alpha}} = log(1.7)$, ${\sigma_{\alpha}}=1$

${\mu_{\beta}} = 0.5$, ${\sigma_{\beta}}=2$

${\mu_{\theta}} = 0$, ${\sigma_{\theta}}={\sqrt{2}}$

また、${\alpha}$の初期値は${1.7}$, ${\beta}$の初期値は${0.5}$, ${\theta}$の初期値は${0}$とした。

勾配法の学習率は0.001とした。

### ${\theta}$について

アダム・オンドラ, 楢崎智亜, 緒方良行が上位3名となっているあたりは、公式の年間ランキングとほぼ同じ。

今回はその課題にトライしていない(=ファイナルに出場していない)場合は、全て未完登という扱いにしている。

そのため、ファイナルに出場できた回数が影響している。

また、他の選手が登れなかった課題(すなわち${\beta}$が高い難しい課題)を完登していると、${\theta}$が上がる形になっており、

その意味では既存の評価よりも能力を正しく反映できていると考えられる。

### ${\alpha}$, ${\beta}$について
完登者が少ない課題の${\beta}$が大きくなっている。

例えば、Munich_0, Moscow_3は1人しか完登していないので高くなっている。

一方、全員が完登したVeil_1は小さくなっている。

もっとバラけることを期待したのだが、登れた人数に応じて同じスコアになってしまっている。

これはトライしていない = 未完登という扱いが大きく影響していることが考えられ、

各選手の能力値がうまく反映できておらず、完登者の人数の影響が大きすぎることが考えられる。

これを修正するには、リザルトを多変数に変更し、

出場していない場合を別に扱うことで回避できる可能性がある。



## 結論
項目反応理論をクライミングに適用し、クライマーの能力、グレード、識別力が数値化できることを確認した。

今回はワールドカップの結果をデータとしたが、多数のクライマーの実際のジムでの登攀結果を得ることができれば、
クライミングにおけるグレードの標準化ができるのではないかと考えている

登攀結果を2値で示しているが、出場していない場合を別に扱うことや、アテンプト数やゾーンを考慮した確率モデルに拡張することも考えられる。
